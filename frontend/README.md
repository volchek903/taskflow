# Taskflow Mini App

React 19 + TypeScript + Vite. Тёмная тема Slate, интерфейс для Telegram и браузера.

## Запуск

```sh
npm install
npm run dev
```

Локальный адрес: http://127.0.0.1:5189

```sh
npm run check    # проверка TypeScript
npm run build    # проверка типов и production-сборка в dist/
npm run preview  # просмотр production-сборки
```

## Где исходники

- `src/App.tsx` — оболочка, навигация и подключение экранов.
- `src/screens/` — Сегодня, проекты, доска, создание, карточка задачи, входящие и настройки.
- `src/components/` — карточки задач, общие элементы и перетаскивание dnd-kit.
- `src/hooks/useStore.ts` — состояние и localStorage.
- `src/types.ts` — модель данных.
- `src/telegram.ts` — типизированный адаптер Telegram WebApp.
- `src/styles.css` — оформление и адаптивная сетка.
- `index.html` — входная HTML-страница Vite.
- `dist/` — только результат сборки, вручную не редактировать.

## Перетаскивание

Захватите карточку мышью: dnd-kit показывает плавающую карточку и плавно раздвигает соседей. На доске можно переносить между статусами, в том числе в пустые колонки. В «Сегодня» перенос в «Выполнено» завершает задачу. Escape отменяет перенос. Клавиатура: фокус на карточке, Space, стрелки, Space для подтверждения. На сенсорном экране удерживайте карточку 220 мс перед переносом; поведение внутри Telegram нужно дополнительно проверить на реальных iOS/Android.

## Данные

Ключ localStorage `taskflow-v1` совместим с предыдущей версией. Данные сохраняются отдельно для каждого origin (схема, хост, порт). При переходе с 5187 на 5189 браузер откроет отдельное хранилище; прежние данные остаются на старом адресе. В настройках есть экспорт JSON, импорт пока не реализован. Приложение не отправляет задачи на сервер.

## Telegram и размещение

Официальный SDK Telegram подключён в index.html: ready, expand, цвета заголовка и фона, нативная кнопка «Назад», тактильный отклик. Для Mini App разместите dist по HTTPS и настройте этот адрес в BotFather. Токен бота во фронтенд не добавлять. Для серверной авторизации требуется проверять initData на сервере.

Vercel: готов vercel.json, команда сборки npm run build, результат dist. Netlify: команда npm run build, publish directory dist; можно загрузить содержимое dist вручную.

Сервер, бот, уведомления, виджет в сообщении, совместная работа и OAuth Notion пока не реализованы. Пункт Notion в настройках показывает фактический статус «Пока не подключено».
